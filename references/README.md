# Competition reference materials

`official/` contains unmodified competition PDFs, the Excel macro workbook and both DMA/REST Python starter variants. `volatility-decision-support.csv` is the exact user-supplied export. `notes/` contains the earlier workbook/VBA text extraction. `manifest.json` records source URLs, byte counts and SHA-256 hashes.

These files are source evidence, not trading entry points. Do not run the starter scripts alongside the package or copy their placeholder API endpoints into a competition profile. Workbook macros have not been executed. Retain original Rotman copyright notices; the repository’s license does not replace the official materials’ terms.

The canonical operating instructions are in the root README; rule discrepancies and modeling choices are explained in `docs/sources.md` and `docs/algorithms.md`.

Git attributes preserve the archived files’ original line endings and bytes so the manifest checksums remain valid on other checkouts.
